# green-code

Il sito si apre su un e-book interattivo sull'impatto ambientale dell'AI: ciclo di vita dei modelli, ordini di grandezza, acqua e hardware, leve per chi sviluppa, misurazione e regole. La versione estesa accompagna il lettore con fonti, perimetri dichiarati e incertezza esplicita. Si può avviare con qualsiasi server statico dalla cartella del progetto, per esempio:

```sh
python3 -m http.server 8000 --directory public
```

Apri `http://localhost:8000`.

La versione estesa del talk, con scaletta, esempi, note per chi presenta e fonti, è disponibile in [`public/talk.html`](./public/talk.html). La scaletta indicata copre 55 minuti di talk più 10 minuti di domande.
